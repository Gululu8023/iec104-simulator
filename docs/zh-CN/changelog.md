# Changelog

[返回首页](./README.md) | [English](../en-US/changelog.md)

本文档记录 IEC104 Simulator 公开发布版本的变更历史。

格式参考 Keep a Changelog，并遵循语义化版本管理思路。

实际版本内容以各个 Release 页面为准。

## [0.2.0] - 2026-06-26

### Added

- 新增 i18n 国际化支持。
- 新增多语言资源文件，用于统一管理界面文案。
- 新增界面语言切换能力，支持在不同语言之间切换显示。
- 新增英文界面文案，提升非中文用户使用体验。

### Changed

- 调整界面文案加载方式，由硬编码文本改为基于语言资源文件加载。
- 优化 Master 与 Slave 模块的界面文案组织结构，便于后续扩展更多语言。
- 统一部分菜单、按钮、提示信息和状态信息的文案风格。

### Notes

- 本版本为功能更新版本，建议从 `v0.1.0` 升级到 `v0.2.0`。
- 当前公开发布仍以 Windows x64 安装包为主。
- 后续版本将继续完善多语言覆盖范围和界面文案一致性。

## [0.1.0] - 2026-04-13

### Added

- 发布 IEC104 协议模拟器首个公开安装版本。
- 提供 Master 与 Slave 两个独立安装包。
- Master 模拟器支持连接从站设备。
- Master 模拟器支持发送总召、控制、设点、时钟同步等命令。
- Slave 模拟器支持监听主站连接。
- Slave 模拟器支持响应总召、控制等命令。
- 支持点表导入。
- 支持报文查看和结构化解析。
- 支持 SOE 事件记录。
- 支持 PCAP/PCAPNG 报文导出。
- 支持本地数据持久化。

### Notes

- 该版本为首个公开发布版本。
- 当前公开发布主要面向 Windows x64 平台。
