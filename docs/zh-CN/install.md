# 安装说明

[返回首页](./README.md) | [English](../en-US/install.md)

本文档说明 IEC104 Simulator 的下载、安装和启动方式。

## 1. 下载安装包

请前往 GitHub Releases 页面下载最新版本：

- [Releases](https://github.com/Gululu8023/iec104-simulator/releases)

Release 附件中通常包含以下安装包：

- `iec104-simulator-master_x.x.x_x64-setup.exe`
- `iec104-simulator-slave_x.x.x_x64-setup.exe`

其中：

- `master` 安装包用于安装 IEC104 Master 模拟器。
- `slave` 安装包用于安装 IEC104 Slave 模拟器。
- `x.x.x` 表示版本号。
- `x64` 表示 64 位 Windows 安装包。

## 2. 选择安装包

根据使用场景选择安装包：

| 使用场景 | 推荐安装包 |
| --- | --- |
| 模拟 IEC104 主站 | `iec104-simulator-master_x.x.x_x64-setup.exe` |
| 模拟 IEC104 从站 | `iec104-simulator-slave_x.x.x_x64-setup.exe` |
| 本机主从联调 | 同时安装 Master 和 Slave |

## 3. 安装程序

双击下载的 `.exe` 安装包，按照安装向导完成安装。

建议使用默认安装路径。

如果系统弹出安全提示，请确认安装包来源为本仓库 Release 页面后继续安装。

## 4. 启动程序

安装完成后，可通过以下方式启动：

- 从开始菜单启动。
- 从桌面快捷方式启动。
- 从安装目录中直接启动可执行文件。

## 5. Master 模拟器连接从站

启动 Master 模拟器后，通常需要配置以下信息：

- 从站 IP 地址。
- 从站端口。
- 公共地址。
- 传送原因字节数。
- 公共地址字节数。
- 信息体地址字节数。
- 其他通信参数。

配置完成后，点击连接按钮，建立与从站设备的 IEC104 连接。

## 6. Slave 模拟器监听主站

启动 Slave 模拟器后，通常需要配置以下信息：

- 本地监听 IP。
- 本地监听端口。
- 公共地址。
- 点表数据。
- 遥信、遥测、遥控等模拟数据。

配置完成后，启动监听，等待主站连接。

## 7. 语言切换

从 `v0.2.0` 开始，IEC104 Simulator 支持 i18n 国际化功能。

可在设置或语言菜单中切换界面语言。

当前支持的语言包括：

- 简体中文。
- English。

切换语言后，如部分界面未立即刷新，可尝试重启程序。

## 8. 卸载程序

可通过 Windows 系统设置卸载程序：

1. 打开 Windows 设置。
2. 进入“应用”。
3. 找到 IEC104 Simulator Master 或 IEC104 Simulator Slave。
4. 点击卸载。

也可以通过控制面板中的“程序和功能”进行卸载。

## 9. 常见问题

### 9.1 安装包无法运行

请确认系统为 Windows 10 x64 或 Windows 11 x64。

如被安全软件拦截，请确认安装包来源为本仓库 Release 页面。

### 9.2 程序无法连接设备

请检查：

- 目标 IP 地址是否正确。
- 目标端口是否正确。
- 防火墙是否放行。
- 从站设备是否已经启动监听。
- IEC104 参数是否与对端一致。

### 9.3 Slave 无法被主站连接

请检查：

- 本地监听端口是否被占用。
- Windows 防火墙是否允许程序通信。
- 主站连接的 IP 和端口是否正确。
- Slave 模拟器是否已经启动监听。

### 9.4 界面语言没有变化

请检查：

- 当前版本是否为 `v0.2.0` 或更高版本。
- 是否已经在语言设置中选择目标语言。
- 切换语言后是否需要重启程序。
