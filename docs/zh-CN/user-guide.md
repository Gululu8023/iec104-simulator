# 使用说明

[返回首页](./README.md) | [English](../en-US/user-guide.md)

本文档介绍 IEC104 Simulator 的主要界面和基础使用流程。

## 1. 主站模拟器

IEC104 Master Simulator 用于模拟 IEC104 主站，可主动连接从站设备，并发送总召、遥控、遥调、时钟同步等命令。

### 1.1 主站首页

![主站首页](../../assets/screenshots/master-home-linked.png)

主站首页用于管理主站连接状态、通信状态和主要操作入口。

### 1.2 主站未连接状态

![主站未连接状态](../../assets/screenshots/master-home-unlink.png)

在未连接状态下，需要先配置从站 IP、端口和 IEC104 通信参数，然后建立连接。

### 1.3 基本使用流程

1. 启动 IEC104 Master Simulator。
2. 配置从站 IP 地址和端口。
3. 配置 IEC104 通信参数。
4. 点击连接按钮，建立通信连接。
5. 根据测试需求发送总召、遥控、遥调或时钟同步命令。
6. 在报文监控区域查看收发报文和解析结果。

### 1.4 主站遥控

![主站遥控](../../assets/screenshots/master-single-command.png)

主站遥控功能可用于向从站发送控制命令，验证从站遥控处理逻辑。

### 1.5 主站点位历史

![主站点位历史](../../assets/screenshots/master-point-history.png)

点位历史功能可用于查看点位数据变化记录，辅助分析遥信、遥测等数据变化过程。

### 1.6 主站报文监控

![主站报文监控](../../assets/screenshots/master-message-panel.png)

主站报文监控可实时查看通信过程中的收发报文、报文方向、时间和解析结果。

## 2. 从站模拟器

IEC104 Slave Simulator 用于模拟 IEC104 从站，可监听主站连接，并响应主站的总召、控制等命令。

### 2.1 从站首页

![从站首页](../../assets/screenshots/slave-home-linked.png)

从站首页用于查看从站运行状态、监听状态和主站连接状态。

### 2.2 从站未连接状态

![从站未连接状态](../../assets/screenshots/slave-home-unlink.png)

在未连接状态下，需要先配置监听地址、监听端口和 IEC104 通信参数，然后启动监听。

### 2.3 基本使用流程

1. 启动 IEC104 Slave Simulator。
2. 配置本地监听 IP 和端口。
3. 配置公共地址和 IEC104 通信参数。
4. 创建从站或导入点表数据。
5. 启动监听。
6. 使用主站工具连接 Slave 模拟器。
7. 根据测试需求模拟数据变化或事件上送。

### 2.4 创建从站

![从站创建](../../assets/screenshots/slave-create-station.png)

创建从站时，需要配置从站名称、公共地址、点表和相关通信参数。

### 2.5 从站数据模拟

![从站数据模拟](../../assets/screenshots/slave-data-simulated.png)

从站数据模拟功能可用于模拟遥信、遥测、遥控、遥调等数据，便于主站系统联调和协议测试。

### 2.6 从站报文监控

![从站报文监控](../../assets/screenshots/slave-message-panel.png)

从站报文监控可实时查看主站与从站之间的通信报文，辅助定位连接、总召、控制等问题。

### 2.7 从站 SOE 监控

![从站 SOE 监控](../../assets/screenshots/slave-soe-event-panel.png)

SOE 监控用于查看事件顺序记录，适合验证遥信变位、事件上送和时间戳相关逻辑。

## 3. 报文详情

IEC104 Simulator 支持查看报文详情，便于分析具体报文结构和字段含义。

![报文详情](../../assets/screenshots/message-detail-dialog.png)

报文详情功能可用于：

- 查看原始报文。
- 查看报文方向。
- 查看报文时间。
- 查看结构化解析结果。
- 辅助定位通信异常。
- 导出 PCAP 或 PCAPNG 文件用于进一步分析。

## 4. 语言切换

从 `v0.2.0` 开始，IEC104 Simulator 支持 i18n 国际化功能。

当前支持：

- 简体中文。
- English。

切换语言后，如果部分界面没有立即刷新，可尝试重启程序。

## 5. 点表配置

Slave 模拟器支持通过点表配置模拟数据。

点表通常用于描述以下信息：

- 信息体地址。
- 点号名称。
- 数据类型。
- 初始值。
- 变化状态。
- 其他测试参数。

具体点表格式请以当前版本程序中的导入模板或示例文件为准。

## 6. 数据模拟

Slave 模拟器可根据点表数据模拟从站数据。

常见模拟数据包括：

- 遥信。
- 遥测。
- 遥控。
- 遥调。
- 事件数据。

具体支持范围以当前版本程序界面为准。

## 7. 报文导出

IEC104 Simulator 支持导出通信报文，便于使用 Wireshark 等工具进行进一步分析。

常见导出格式包括：

- PCAP。
- PCAPNG。

导出的报文文件可用于：

- 问题复现。
- 协议分析。
- 测试报告。
- 与第三方工具联动分析。

## 8. 使用建议

建议在测试前确认以下事项：

- 主站和从站的 IP、端口配置正确。
- IEC104 参数与对端保持一致。
- Windows 防火墙允许程序通信。
- 测试点表与实际测试场景匹配。
- 版本号与文档说明一致。

## 9. 问题反馈

如发现问题，请在 GitHub Issues 中提交反馈，并尽量提供以下信息：

- 软件版本号。
- 操作系统版本。
- 使用的是 Master 还是 Slave。
- 问题复现步骤。
- 报错截图。
- 相关日志或报文文件。
