# IEC104 Simulator v1.0.0

> Release date / 发布日期：在创建 Release 时填写实际日期。

## 中文

v1.0.0 是 IEC104 Simulator 首次完整源码公开版本，包含独立的 Master 和 Slave Windows x64 应用。

### 亮点

- Master/Slave 双应用及共享 Rust backend/parser workspace。
- 总召、组召、电度召唤、控制、设点、系统命令和单节文件传输。
- 从站命令映射、SOE、SQ=1、15 种数据模拟波形、强制上送和雪崩测试。
- 点表预检与导入、报文树形解析及 CSV/TXT/PCAP/PCAPNG 导出。
- 有界网络背压、统一自动重连、任务生命周期和批量持久化稳定性修复。

### 下载

创建 Release 时列出实际上传的 Master/Slave Windows x64 安装包及其 SHA-256；不得保留占位附件名或校验值。

Windows 运行依赖 WebView2，缺失时默认安装器可能需要联网获取。

### 升级警告

v1 不迁移 pre-v1 数据库。升级前请备份 `iec104_simulator.db`、点表和配置。遇到不兼容错误时，保留备份并重命名旧数据库，再启动 v1 创建新库。详见[README](../../README.md#下载安装与升级)。

### 已知限制

请阅读[协议支持范围与已知限制](../zh-CN/protocol-support.md)。本工具不用于生产调度或安全控制系统。

## English

v1.0.0 is the first release that publishes the complete IEC104 Simulator source, with separate Master and Slave Windows x64 applications.

### Highlights

- Separate Master/Slave apps with shared Rust backend and parser workspace crates.
- Interrogation, controls, setpoints, system commands, and single-section file transfer.
- Slave mapping, SOE, SQ=1, 15 simulation waveforms, force upload, and avalanche testing.
- Point-table preview/import, tree parsing, and CSV/TXT/PCAP/PCAPNG frame export.
- Reliability fixes for bounded backpressure, reconnect, task lifecycle, and batched persistence.

### Downloads

At release time, list only the actual Windows x64 Master/Slave attachments and their SHA-256 values. Do not publish placeholder artifact names or hashes.

WebView2 is required; the default installer may need network access if it is missing.

### Upgrade warning

v1 does not migrate a pre-v1 database. Back up `iec104_simulator.db`, point tables, and configuration. If v1 reports an incompatible schema, preserve and rename the old database before allowing v1 to create a new one. See the [English README](../en-US/README.md#download-installation-and-upgrade).

See [Protocol Support and Known Limitations](../en-US/protocol-support.md) and the full [Changelog](../../CHANGELOG.en.md).
